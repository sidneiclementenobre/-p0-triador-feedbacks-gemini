# Projeto P0 — Triador de Feedbacks com IA (Google Gemini)

**Problema resolvido:** Classificar avaliações de clientes em categorias de sentimento (Positivo, Neutro ou Negativo) e extrair os pontos críticos mencionados de forma estruturada.

### Como configurar e executar este projeto:
1. Clique no botão azul **Open in Colab** dentro do arquivo `.ipynb` acima.
2. No menu lateral esquerdo do Google Colab, clique no ícone de **Chave (Secrets)**.
3. Adicione um segredo chamado `GEMINI_API_KEY` com a sua chave gratuita do Google AI Studio.
4. Ative a permissão de acesso ao notebook e execute as células em ordem.
